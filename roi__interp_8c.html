int roi_interp_at ( const roi_interp_t *  model,
int  pos,
rois_t *  out 
)

Linearly interpolate blob ROIs for servo step pos.

t = (pos - pos0) / (pos1 - pos0); each of cx, cy, rx, ry, angle is lerped. Extrapolation outside [pos0, pos1] is allowed.

Parameters
modelTwo-point calibration.
posServo step.
outFilled with interpolated blobs (same names/count as endpoints).
Returns
0 on success, -1 if model is invalid.
