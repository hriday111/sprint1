Detailed Description

tuibox UI for disease assignment + Start/Reset sweep controls.

Used by the main measurement binary sweep_run after build/driver is up.

Screen 0: pick D1–D10 for blob 1, then blob 2 (left list). Screen 1: Start / Reset / progress; footer shows Blob → disease.

Note: do not include tuibox.h here — it is a header-only library and must be compiled into exactly one translation unit (sweep_tui.c).
