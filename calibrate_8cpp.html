Detailed Description

One-shot ROI recalibration after optical changes (lens move, remount).

Day-to-day measurements do not need this: start servo_calib, then sweep_run. Prefer calibrate2 when recalibrating; if detection fails, try exposures 0.20, 0.14, and 0.10 and keep the best overlay.

Grabs a single crop, runs detect_boxes_cv, writes rois.json and diagnostic images under tmp/. Does not stop servo_calib.

Usage: ./calibrate [exposure_ms=0.1] [n_blobs=3] [roi_path]
