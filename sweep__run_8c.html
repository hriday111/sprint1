Detailed Description

Main measurement tool: disease-assignment TUI + intensity sweep.

Normal workflow (ROI calibration is already done for the current optics):

  1. Start the driver: ./build/servo_calib
  2. Run this tool: ./camera-sdk/build/bin/sweep_run

Flow: pick D1–D10 for blob 1 and blob 2 → Start/Reset screen → CSV. Requires servo_calib already running.

Usage: ./sweep_run [rois.json] [exposure_ms] [out.csv]

Exit leaves the servo daemon running (FIFO closed without -1). Recalibrate with calibrate2 only after lens moves; try exposures 0.20, 0.14, and 0.10 if detection looks wrong.
