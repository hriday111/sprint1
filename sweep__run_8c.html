Detailed Description

Friendly TUI for a step-by-step intensity sweep over saved.prm.

Shows a colorful Start / Reset screen for non-technical operators. Start runs the scan (FIFO move + ROI means → CSV). Reset parks at prep and prepares for another run. Requires servo_calib already running.

Text is wrapped with vt100utils (via tuibox) so colored lines reflow when the terminal is resized.

Usage: ./sweep_run [rois.json] [exposure_ms] [out.csv]

Exit leaves the servo daemon running (FIFO closed without -1).
