Detailed Description

Step-by-step intensity sweep over the scan window in saved.prm.

For each step from start to stop inclusive: move via FIFO, grab a crop, average each ROI, append one CSV row. Requires servo_calib already running.

Usage: ./sweep_run [rois.json] [exposure_ms] [out.csv]

Warning
Closing the command FIFO sends -1, which exits servo_calib.
