Detailed Description

Integer command codes for the servo FIFO protocol and homing offsets.

Absolute positions use the range [CMD_ANGLE_MIN, CMD_ANGLE_MAX]. Values above that range are control commands.

Note
CMD_DISABLE and CMD_RESET share the value 1003. In stepperSend, the disable branch is evaluated first, so the reset path is unreachable.
