Detailed Description

Client side of the device FIFO protocol (camera tools → device daemon).

Line formats the daemon understands (see main handle_command):

  • N\n absolute move / motor command (integer)
  • bN\n illumination brightness 0..255
  • 1001\n illumination on (CMD_LASER_ON)
  • 1002\n illumination off (CMD_LASER_OFF)
  • 4000\n get position → reply on POS_PIPE
  • -1\n stop daemon
