void crash_setup ( void  )

Raise RLIMIT_CORE and install handlers for fatal signals.

On SIGSEGV/SIGABRT/SIGBUS/SIGFPE/SIGILL/SIGQUIT/SIGSYS the handler logs where the core dump is expected, flushes the logger, then re-raises so the kernel writes the dump.

Call after the file logger is initialized.
